## 本次新增的关键发现
1. **Access gate 先于副作用**：registry → admin → rule → default → class；被拒 read 先于存在性检查，被拒 write 不跑 detector / 不落 store / 不建快照。
2. **LlamaIndex 读路径绕过 ACL**：`GuardedChatStore.get_messages()` 直读底层；outsider 的 `guard.read` 被拒，但 `store.get_messages` 返回 `SECRET`（fake backend 复现）。
3. **适配器公开 `.guard`**：`store.guard.read(..., principal=...)` 可冒充任意 principal，`AgentHandle` 的不可覆写边界在适配器对象上失效。
4. **HTTP server 无认证且不传 principal**：per-agent ACL 在 HTTP 路径不可用；`/reset` 无认证。
5. **REDACT 容器退化**：dict/list 被 `_stringify` 后返回字符串，结构丢失（`'token: [REDACTED:github_token]\nn: 1'`）。
6. **版本 provenance 歧义**：release `5a2ac20` 早于安全修复；当前 tag `v0.4.0` 含修复；CHANGELOG 仍列 `[Unreleased]`；`pyproject` 仍 0.4.0。
